# Teen Depression Risk Prediction

## Overview
This project uses machine learning models to predict depression risk among teenagers.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Models Tested
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Results
KNN achieved approximately 97.4% cross-validation accuracy.

## Key Findings
Anxiety level, academic pressure, and sleep habits were among the strongest predictors.
